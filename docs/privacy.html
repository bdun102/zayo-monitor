Zayo Ticket Monitor - Privacy Policy

Last updated: February 6, 2026

Overview

Zayo Ticket Monitor is a Chrome extension that monitors Zayo TranZact ticket pages for status updates and sends desktop notifications when changes are detected. This policy explains what data the extension accesses and how it is handled.

Data Collection

This extension does not collect, store, or transmit any personal data. It does not track users, use analytics, set cookies, or communicate with any server other than what is described below.

Data Accessed Locally

The extension reads the "Last Update Date/Time" field from Zayo TranZact ticket pages open in your browser. This value is stored locally in Chrome's extension storage on your device solely to detect changes between refresh cycles. The monitored ticket list and refresh settings are also stored locally.

External Requests

The extension makes a single external request to a GitHub-hosted JSON file to check for new versions of the extension. This request contains no user data. No other external requests are made.

Permissions

The extension requires access to tranzact.zayo.com to read ticket timestamps and display a monitoring badge. It does not access any other websites or domains.

Third Parties

No data is shared with or sold to third parties. No data leaves your device.

Changes

If this policy is updated, the changes will be reflected on this page with an updated date.

Contact

For questions about this policy, open an issue on the GitHub repository.
